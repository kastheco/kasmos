# guides

Practical walkthroughs for day-to-day kasmos usage. These guides assume you have already completed `kas setup` and can launch the TUI with `kas`. If you haven't done that yet, start with [getting started](../getting-started/index.mdx).

## in this section

- [tui overview](./tui-overview.mdx) — keymap reference, layout, panes, and how to navigate the interface
- [creating plans](./creating-plans.mdx) — how to describe work, spawn a planner, and get a structured plan into the store
- [running implementations](./running-implementations.mdx) — normal wave-based flow, blueprint skip for small tasks, and the elaboration phase
- [interactive resource controls](./interactive-resources.mdx) — reduce agent CPU and I/O priority when running kasmos alongside games or latency-sensitive workloads
- [reviewing and merging](./reviewing-and-merging.mdx) — reviewer spawn, approval vs changes requested, pull requests, and merge
- [managing instances](./managing-instances.mdx) — start, attach, detach, pause, resume, checkout, kill, stop, and adopt orphaned sessions
