# Codex Desktop Linux handoff

This directory contains the reference host adapter and disabled-by-default feature template for mounting the exported Kasmos monitor in Codex Desktop Linux.

It patches nothing in this repository and does not modify the Codex fork. Applying and completing the ASAR descriptors is a separate task against the separate `codex-desktop-linux` repository.

The contract test keeps the feature metadata, widget host interface, exported manifest, and reference adapter aligned.
